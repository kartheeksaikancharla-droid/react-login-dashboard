# React Login and Dashboard

A simple React + Vite application with a login page, dashboard, logout, and localStorage session persistence.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Demo login

- Email: `admin@gmail.com`
- Password: `123456`

## Build

```bash
npm run build
```

## GitHub

Create an empty repository on GitHub, then run these commands from this project folder:

```bash
git init
git add .
git commit -m "Create React login dashboard"
git branch -M main
git remote add origin https://github.com YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

Replace the remote URL with the HTTPS URL copied from your own GitHub repository.

## Important

This is a learning/demo login. Credentials are checked in frontend code, so it is not secure for real accounts. Use a backend and hashed passwords for production.
